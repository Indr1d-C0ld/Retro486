I built a real 486 PC that runs in a web page. 🖥️💾

Not "DOS in a box" — an actual 1993 machine, emulated chip by chip, served from my own home server and booting in the browser tab.

Meet Retro486.

⚙️ The machine
Under the hood is 86Box, the cycle-paced PC emulator, compiled to 64-bit WebAssembly with threads. That means the real Award BIOS of an ASUS VL/I-486SV2GX4 motherboard (SiS 471, VESA Local Bus), a real S3 video BIOS, a Sound Blaster 16 and a Roland MT-32 driven through an intelligent-mode MPU-401 — the way Sierra games expected it in 1990.

The CPU runs at its true clock. A DX-33 does exactly what a DX-33 did. Nothing gets "turbo'd" by accident.

🧩 Fully configurable hardware
Pick any 486 motherboard 86Box ships a BIOS for, then 64 real CPUs for it — Intel, AMD and Cyrix, from a 486SX-20 to a 5x86-160 and the Pentium OverDrive — plus RAM, video card (S3 805/928/Trio, ET4000, Cirrus…), sound card, MIDI module (MT-32 old/new, CM-32L), mouse, floppies, CD-ROM. Every choice is filtered against the emulator's own catalogue, and the full 86Box settings dialog is one click away for the deep stuff: wait states, controllers, ports, per-device options.

💽 A hard disk built from scratch
The C: drive is generated by a script, no emulator involved: my own MBR in 227 bytes of x86 assembly, a FAT16 partition, the original MS-DOS 6.22 boot sector, IO.SYS and MSDOS.SYS laid out the way the loader wants them, and every file from the four install floppies decompressed with a hand-written decoder for Microsoft's KWAJ format. Add a CONFIG.SYS boot menu (XMS+EMS / XMS / minimal), CD-ROM on D:, a mouse driver and an Italian keyboard — 247 MB that compress to 6.5 MB for the first download.

📂 A file manager for the virtual disk
Power the PC off and browse C: right from the page: preview files, edit AUTOEXEC.BAT and CONFIG.SYS (code page 437, accents included), drag files and whole folders in. Only the changed 64 KB blocks get written back, and one click saves the disk to the server, which keeps the last three versions.

🎮 One-click games
The library writes a launcher batch file into the disk and the game starts on boot, with the right sound driver for your MIDI setup. First title in: Leisure Suit Larry 3, in my own complete Italian translation — with its soundtrack on the emulated MT-32.

📺 A CRT you can tune
A WebGL2 shader turns every frame into a tube: curvature, Gaussian scanlines, aperture-grille / dot / slot masks, bloom, phosphor persistence, convergence errors, noise, flicker, glass reflection, green and amber monochrome. Presets go from a 1992 14" VGA to a Trinitron. No GPU? A second renderer on Canvas 2D kicks in with the same controls.

🎨 Dressed for 1993
The whole portal is a text-mode BIOS/DOS interface: 16-colour palette, double-line boxes with drop shadows, F-key navigation, and an 8x16 VGA font extracted from an LGPL VGA BIOS. Icons, beige tower (with the MHz on its 7-segment display), CRT bezel and desk scene are pixel art made with PixelLab.

🏠 Self-hosted
It lives on my own Debian box, Balthasar: Apache, a small PHP backend for disks, hardware profiles, CMOS and media, cross-origin isolation for the threads, password-protected.

📏 Honest numbers
In-browser 86Box runs its interpreter (its dynamic recompilers emit x86 code WebAssembly can't run). On my desktop a 486DX-33 runs at 93-100% of real speed; a DX2-66 at about half. The clock never lies — past that point the whole machine slows down evenly. A WebAssembly recompiler is the next frontier.

Pressing F10 and hearing the MT-32 boot after the Award POST, in a browser tab, still feels like magic. ✨
